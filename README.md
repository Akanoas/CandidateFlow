
# CandidateFlow

CandidateFlow is a full-stack applicant tracking system built for WGU D424 Software Engineering Capstone (Task 3).
Author: Abdoul Assirou Akano

## Tech Stack
- Backend: Java 21, Spring Boot 3, Spring Security, Hibernate
- Frontend: React 18, TypeScript, Vite, Tailwind CSS
- Database: PostgreSQL (Dockerized)

## Running the Application
1. Start database: `docker-compose up -d`
2. Start backend: `cd backend && ./mvnw spring-boot:run`
3. Start frontend: `cd frontend && npm run dev`
